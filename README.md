# Databricks Bootcamp

Notebook-based data engineering practice covering data preparation and transformation workflows in Databricks.

## Contents

- `code/` — notebooks and transformation work
- `datasets/` — input data used by the notebooks

## Skills Demonstrated

- Notebook-based development
- Data transformation and analysis
- Working with structured datasets in a Databricks-style workflow

## Usage

1. Import the notebooks into a Databricks workspace.
2. Upload the datasets to the workspace or accessible storage location.
3. Update input paths where necessary.
4. Run the notebooks from the first transformation step through the final output.

This repository is a learning portfolio and will be expanded with clearer project outcomes, screenshots, and reproducible outputs.
